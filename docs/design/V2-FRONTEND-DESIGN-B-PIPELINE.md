# V2 前端设计书 B：流程管线方向（流程即界面）

状态：**设计评审稿（未实现，不改变任何行为）**。编制日期：2026-09-30。
定位：三份候选前端设计方向之一（另见 `V2-FRONTEND-DESIGN-A-WORKBENCH.md`、`V2-FRONTEND-DESIGN-C-GALAXY.md`）。
三份覆盖**同一套功能基线 F1–F12**（见 A 档 §2，本档 §2 只写映射差异）。

---

## 1. 设计方向

| 项 | 内容 |
|---|---|
| 核心创意 | **流程即界面**：主视图就是一张活的 V2 交付流程图——`提交 → 编写 → 评审 → 四带门 → 验收 → 提升`。节点随真实任务状态点亮、阻塞、失败；**节点本身就是操作与详情的入口**，不存在"图归图、功能归功能"的两套界面 |
| 气质参考 | 工程蓝图（blueprint）+ 地铁线路图：深蓝底、线框节点、等宽标注；可视化是**结构表达**而非装饰 |
| 适合场景 | "可以做一个总图显示我们的进程现在在做什么，且这张图会随着进程的变化而更新状态"的直接回应；向他人演示系统时最直观 |
| 字体声明 | 标题/阶段名：**Unbounded**（500/700 两极字重）；标注/数据：**JetBrains Mono**；中文正文：思源黑体。管线上的标注一律小号等宽大写字距 |
| 色彩 | 蓝图底 `#0b1d3a`，叠加 40px 工程网格线（`#16305c`，8% 透明）；线框与文字 `#cfe4ff`；强调色信号橙 `#ff5c1a`（当前阶段与异常）；通过节点青绿 `#2dd4a7`。**禁止紫/靛蓝渐变**；节点无圆角（直角方框 + 单点切角，蓝图语言） |

## 2. 功能覆盖（F1–F12 映射；与 A/C 共用基线定义）

| # | 功能 | 管线方向落点 |
|---|---|---|
| F1 | 创建任务 | 管线起点「＋提交」节点 → 右侧抽屉表单（向导内容与 A 档一致） |
| F2 | 阶段进度可视化 | **本体**：六个阶段为管线主节点，状态=节点形态（空心=未到达 / 描边流动=进行中 / 实心=通过 / 红叉=失败 / 琥珀停靠=人工闸门） |
| F3 | worker 可见性 | 编写/评审节点为**泳道容器**：节点内纵向列出 worker 子节点（身份、分工标题、最近活动时间），单作者多工作者一眼可见 |
| F4 | 实时更新 | SSE 驱动节点状态机；状态迁移播放 300ms 描边流动动画（reduced-motion 下仅变色）；图右上角 `as_of` 时钟 |
| F5 | 给主作者下指令 | 选中「编写」节点 → 底部指令条升起（锚定节点，不是全局聊天框）；注入记录作为**节点上的可点标记**，三档状态（排队/已接收/已落实）直接画在节点角标 |
| F6 | 调整 worker 分工 | 选中 worker 子节点 → 同一指令条，目标自动锁定该 worker；历史指令沿节点左侧时间轴排列可追溯 |
| F7 | 差异与证据 | 选中「评审/验收/提升」节点 → 右侧抽屉（差异树、证据卡、提交 OID、祖先关系）；抽屉不遮图，可同时看图定位 |
| F8 | 异常与恢复 | 失败节点红色描边常亮；点击进入「恢复计划」抽屉（先算计划、锁内复核、409 强制刷新）；崩溃恢复成功的节点带「已恢复」徽标 |
| F9 | 人工闸门 | 门禁节点琥珀停靠态 + 待决路径列表悬浮卡；批准仅 CLI 签名，卡片内给出命令提示，**无批准按钮** |
| F10 | 能力分级 | 未接通能力在图上**不画节点**（如 DAG 分支、自动修复环）；数据源 `unverifiable` 时对应节点变灰并标问号，**绝不显示为"正常"** |
| F11 | 只读/写边界 | 图左上角模式徽标；写模式下可选中节点才出现指令条；页尾密钥声明（同 A 档） |
| F12 | 可访问性 | 图同时提供「列表视图」切换（语义化表格，内容与图一一对应）；键盘 Tab 按流程顺序遍历节点，Enter 打开抽屉 |

## 3. 信息架构

```text
┌──────────────────────────────────────────────────────────┐
│ 模式徽标 · 任务选择器 · as_of · 列表/管线切换 · 不可核验计数   │
├────────────────────────────────────────────┬─────────────┤
│                                            │ 右侧抽屉      │
│   [＋提交]─▶[编写]─▶[评审]─▶[四带门]─▶[验收]─▶[提升]  │ 360px      │
│              ┊ worker 泳道（节点内纵向排列）    │ 差异/证据/   │
│              ┊ ├ w1 分工标题 · 3 分钟前活动     │ 恢复计划/    │
│              ┊ └ w2 分工标题 · 注入标记②       │ 待决项       │
│                                            │             │
│   多任务时：任务选择器切换管线（首版单任务一图，      │             │
│   不做多管线并列缩略——避免"看起来很多其实读不出")      │             │
├────────────────────────────────────────────┴─────────────┤
│ 指令条（选中节点时升起）· 页尾密钥声明                        │
└──────────────────────────────────────────────────────────┘
```

页面：**管线总图（默认首页，即"总图"）**、节点抽屉（替代独立详情页）、创建抽屉、异常中心（复用 A 档表格视图）、执行器与环境。

## 4. 关键交互

1. **一图读懂**：进入首页 3 秒内应能回答"卡在哪一步、谁在干活、有没有要我处理的"。当前阶段节点信号橙流动描边；待人工琥珀常亮+待决数角标。
2. **节点即入口**：单击选中（描边加粗）→ 抽屉；双击 worker 子节点 → 指令条预填目标；Esc 逐层退出。
3. **指令标记**：每条注入指令是指令节点上的编号角标，点击展开三档状态与证据；**落实前不改变任何节点状态**。
4. **缩放与聚焦**：滚轮缩放（0.5×–2×），双击空白回到适配；节点过多时 worker 泳道折叠为「3 workers ▾」。

## 5. 视觉与动效

- 加载编排：网格底 → 管线骨架描线动画（600ms，一笔画）→ 节点错峰点亮（80ms 步进）→ 标注淡入。**只演一次**，状态更新不重播。
- 连接线用 1px 实线；数据流向用线段上的短划线位移动画（`stroke-dashoffset`，12s 线性循环，reduced-motion 下静止）。
- 背景材质：蓝图网格 + 极淡噪点；**无渐变光晕、无发光滤镜堆叠**（蓝图靠线稿取胜）。

## 6. 技术方案

- **SVG** 渲染管线（不用 Canvas/Three）：节点即 DOM 可聚焦元素，天然键盘可达、可选中复制；视图框 `viewBox` 缩放。
- 布局：阶段水平固定槽位，worker 泳道节点内自动撑高；不做力导向布局（流程是确定结构，不需要物理模拟）。
- 状态层：SSE → 节点状态机 reducer → 只更新变化节点（`data-state` 属性驱动 CSS）；与 A 档共用 read-api。
- 列表视图与管线视图共用同一数据层，保证语义等价（可访问性硬要求）。

## 7. 与后端契约对齐

同 A 档 §7（单一写者、纯读取查询、幂等键、`unverifiable` 纪律、CLI 签名边界）。管线特有的约束：
**节点状态只能来自任务记录/锁/事件的投影，禁止前端根据时间流逝自行推进节点**（无数据 = 保持上一已核验状态 + `stale` 标注）。

## 8. 验收标准（方向特有）

- 打开页面 3 秒内能指出当前阶段与待人工项（可用性测试口径）。
- 注入指令 → 节点角标出现 → 三档状态迁移全程在图上可见，无需刷新。
- 键盘 Tab 顺序 = 流程顺序；列表视图与管线视图信息逐项等价。
- 60fps：单任务 20 worker 泳道下缩放/状态动画不掉帧（performance 面板采样）。

## 9. 取舍与风险

- 优点：最贴合"总图 + 随进程更新"的原始诉求；演示效果强；实现仍是 2D DOM 技术，风险可控。
- 代价：阶段数固定（V2 流程恰好是线性六段，**这是该方向成立的前提**；若未来引入多步骤 DAG，布局需重设计）。
- 风险：管线图沦为装饰——约束：图上不允许存在"无数据绑定、纯装饰"的元素。
